📚 Not Kayıt Sistemi

C# Windows Forms ve MS SQL Server ile geliştirilmiş basit bir öğrenci not kayıt uygulaması.

Özellikler
Öğretmen paneli: Öğrenci ekleme (numara, ad, soyad)
Not girişi: 3 sınav notunu girip güncelleme
Otomatik hesaplama: Ortalama ve Geçti/Kaldı durumu (geçme sınırı 50)
İstatistikler: Sınıf ortalaması, geçen ve kalan öğrenci sayısı
Öğrenci paneli: Öğrenci numarasıyla kendi notlarını ve durumunu görüntüleme
Kullanılan Teknolojiler
C# / .NET Framework
Windows Forms
MS SQL Server (SQLEXPRESS)
ADO.NET (SqlConnection, SqlCommand)
